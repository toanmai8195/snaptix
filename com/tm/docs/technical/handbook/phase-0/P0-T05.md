## `make help` tự sinh từ comment `##`
- **Chủ đề**: `make`
- **Bối cảnh**: danh sách lệnh phải luôn khớp Makefile, không viết tay ở README rồi lệch.
- **Cách làm & lý do**: mỗi target ghi `target: ## mô tả`; `help` dùng `awk` đọc `$(MAKEFILE_LIST)` in các dòng có `## `. `.DEFAULT_GOAL := help` → gõ `make` không làm gì nguy hiểm.
- **Bẫy / lưu ý**: trong recipe của Make, `$` phải viết `$$` (`$$1`, `$$(go list ...)`) để Make không nội suy trước khi đưa cho shell. Mỗi dòng recipe chạy một shell riêng → `cd dir && lệnh` phải cùng một dòng.
- **Code**: [Makefile#L13-L14 — help](../../../../../../Makefile#L13-L14)

## Biến `PROJECT` để test không đụng dữ liệu dev
- **Chủ đề**: `make`, `docker/compose`, `testing`
- **Bối cảnh**: test `make up/down/nuke` thật mà không xoá dữ liệu stack dev.
- **Cách làm & lý do**: `PROJECT ?= snaptix` (`?=` = chỉ gán khi chưa có) và `docker compose -p $(PROJECT)`; test chạy `make up PROJECT=snaptix-test`. `down` giữ volume, `nuke` mới `down -v` — tên target cảnh báo rõ hành động phá dữ liệu.
- **Code**: [Makefile#L6-L7 — PROJECT, COMPOSE](../../../../../../Makefile#L6-L7)

## `make test` = đúng các bước CI
- **Chủ đề**: `make`, `ci`
- **Bối cảnh**: "máy tôi pass mà CI fail" thường do local chạy lệnh khác CI.
- **Cách làm & lý do**: `test: test-repo test-server test-app`, mỗi target gọi `scripts/ci/run.sh repo|server|app` — cùng script mà GitHub Actions gọi. Test ngược: thêm test Go fail cố ý → `make test` exit khác 0.
- **Code**: [Makefile#L41 — test](../../../../../../Makefile#L41)

## Đo P0-AT01 trên bản clone chưa commit
- **Chủ đề**: `git`, `testing`
- **Bối cảnh**: nghiệm thu "clone mới → `make up && make migrate` < 5 phút" trước khi commit.
- **Cách làm & lý do**: tree sạch → `git clone` thật; chưa sạch → snapshot bằng index tạm (`GIT_INDEX_FILE` + `read-tree HEAD` + `add -A` + `checkout-index`), đúng nội dung clone sẽ có sau commit. Kết quả 8s vì image đã cache — máy mới cần thêm thời gian pull image.
- **Code**: [scripts/test/make.test.sh](../../../../../../scripts/test/make.test.sh)
