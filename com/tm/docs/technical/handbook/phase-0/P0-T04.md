## Go module và module path
- **Chủ đề**: `go/modules`
- **Bối cảnh**: cần một đơn vị quản lý code + dependency cho toàn bộ Go trong `com/tm/server`.
- **Cách làm & lý do**: `go mod init github.com/toanmai8195/snaptix/com/tm/server` — module path là **tiền tố import** của mọi package (`…/com/tm/server/pkg/probe`), đặt theo URL repo theo quy ước Go. Dòng `go 1.24.1` là phiên bản Go tối thiểu. **Một** `go.mod` cho cả core, stats-worker, `pkg/` → cùng một phiên bản mỗi thư viện, import lẫn nhau không cần cấu hình.
- **Code**: [go.mod](../../../../server/go.mod)

## Bazel: hermetic, cache theo nội dung, bzlmod
- **Chủ đề**: `bazel`
- **Bối cảnh**: cần build tái lập giữa máy dev và CI, chỉ build/test phần bị ảnh hưởng, build image không cần Docker (P0-T07).
- **Cách làm & lý do**: `.bazelversion` (Bazelisk đọc để chọn đúng bản 8.7.0); `MODULE.bazel` khai báo `rules_go`, `gazelle`, Go SDK Bazel tự tải (`go_sdk.download`), dependency Go lấy từ `go.mod` (`go_deps.from_file`); `MODULE.bazel.lock` commit để resolve tái lập; `.bazelrc` bật Go thuần + tắt CGO (không cần C compiler, binary tĩnh). Cái giá: mỗi package cần `BUILD.bazel` — Gazelle sinh hộ.
- **Bẫy / lưu ý**: `~/.bazelrc` của máy cũng được đọc ở mọi workspace (vd cấu hình CA công ty). Symlink `bazel-bin`, `bazel-out`… trỏ vào output base ngoài repo — đã ignore bằng `bazel-*`.
- **Code**: [MODULE.bazel](../../../../server/MODULE.bazel), [.bazelrc](../../../../server/.bazelrc)

## Gazelle, package, target, label
- **Chủ đề**: `bazel`, `gazelle`
- **Bối cảnh**: không muốn viết tay `BUILD.bazel` cho từng package Go.
- **Cách làm & lý do**: target `//:gazelle` + directive `# gazelle:prefix …` (phải khớp module path) và `# gazelle:go_naming_convention import` (target tên theo package thay vì `go_default_library`). Gazelle đọc `package` + `import` của code → sinh `go_library` / `go_test` (`embed = [":probe"]` để test cùng package). Khái niệm: thư mục có `BUILD.bazel` là **package**, mỗi khai báo là **target**, tên đầy đủ là **label** `//pkg/probe:probe`, `//...` = mọi target.
- **Bẫy / lưu ý**: Bazel cache theo **nội dung** file nên test có thể báo `(cached)` ngay lần đầu nếu đúng nội dung đó từng được chạy. Code phải build được bằng cả `go` và Bazel.
- **Code**: [BUILD.bazel](../../../../server/BUILD.bazel)

## Thêm thư viện ngoài: go.mod là nguồn sự thật
- **Chủ đề**: `go/modules`, `bazel`
- **Bối cảnh**: `import "github.com/google/uuid"` → `bazel build` lỗi vì Bazel chưa biết repo này.
- **Cách làm & lý do**: thứ tự `go get` → `go mod tidy` (đồng bộ `go.mod` với import, sinh `go.sum` chứa hash chống giả mạo) → `bazel mod tidy` (tự thêm `use_repo(go_deps, "com_github_google_uuid")`) → `bazel run //:gazelle` (thêm `deps = ["@com_github_google_uuid//:uuid"]`). Phiên bản chỉ khai báo ở `go.mod`, không lặp lại trong `MODULE.bazel`.
- **Bẫy / lưu ý**: tên repo Bazel đảo tên miền: `github.com/google/uuid` → `com_github_google_uuid`; `@` = repo ngoài workspace.
