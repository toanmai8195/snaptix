## `signal.NotifyContext` biến tín hiệu thành huỷ context
- **Chủ đề**: `go/context`, `go/signal`
- **Bối cảnh**: K8s/Docker gửi SIGTERM trước khi kill; dev bấm Ctrl+C (SIGINT).
- **Cách làm & lý do**: `ctx, stop := signal.NotifyContext(ctx, syscall.SIGTERM, os.Interrupt)` — tín hiệu đầu tiên huỷ `ctx`, mọi thứ đã nhận `ctx` tự biết phải dừng. `defer stop()` trả lại hành vi mặc định: tín hiệu thứ hai sẽ kill ngay (thoát khẩn cấp khi dừng êm bị treo).
- **Code**: [main.go#L33 — NotifyContext](../../../../server/services/core/cmd/server/main.go#L33)

## `http.Server.Shutdown` và `context.WithoutCancel`
- **Chủ đề**: `go/http`, `go/context`
- **Bối cảnh**: ngừng nhận kết nối mới nhưng để request đang chạy chạy xong, có giới hạn thời gian.
- **Cách làm & lý do**: `Shutdown(ctx)` đóng listener ngay (kết nối mới bị từ chối), chờ connection đang hoạt động về idle; hết hạn `ctx` thì trả lỗi → gọi `Close()` để cắt cưỡng bức. `ctx` gốc đã bị huỷ nên phải tạo context mới: `context.WithTimeout(context.WithoutCancel(ctx), timeout)` — giữ value (trace, request ID) nhưng bỏ tín hiệu huỷ. `srv.Serve` trả `http.ErrServerClosed` sau `Shutdown` — đó là kết thúc bình thường, không phải lỗi.
- **Bẫy / lưu ý**: dùng thẳng `ctx` đã huỷ cho `Shutdown` → trả lỗi ngay, request đang chạy bị cắt — đúng cái cần tránh.
- **Code**: [serve.go#L27-L39 — Shutdown/Close](../../../../server/services/core/internal/httpx/serve.go#L27-L39)

## Thứ tự dừng: server trước, pool sau
- **Chủ đề**: `go/structure`, `pg`
- **Bối cảnh**: request đang chạy khi dừng vẫn cần DB.
- **Cách làm & lý do**: `pool.Close()` đặt trong `defer` của `run`, còn `Serve` được `return` ở cuối → `Serve` (chờ request xong) chạy hết rồi `defer` mới đóng pool. Log `database pool closed` sau `http server stopped` chứng minh thứ tự.
- **Code**: [main.go#L48-L63](../../../../server/services/core/cmd/server/main.go#L48-L63)

## Truyền `net.Listener` để test shutdown thật
- **Chủ đề**: `go/testing`, `go/http`
- **Bối cảnh**: cần kiểm "request đang chạy vẫn hoàn thành", "kết nối mới bị từ chối", "quá timeout thì cắt" bằng TCP thật, không mock.
- **Cách làm & lý do**: `Serve` nhận listener → test dùng `net.Listen("tcp", "127.0.0.1:0")` (cổng ngẫu nhiên, chạy song song được). Handler chậm dùng `select` giữa `time.After` và `r.Context().Done()` để goroutine không bị treo sau khi kết nối bị cắt. Chạy `-race -count=3` để bắt test chập chờn do timing.
- **Code**: [serve_test.go](../../../../server/services/core/internal/httpx/serve_test.go)
