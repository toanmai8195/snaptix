## Makefile là mục lục lệnh, không chứa logic
- **Chủ đề**: `make`, `tooling`
- **Bối cảnh**: người mới clone repo cần một chỗ để biết "chạy gì"; lệnh thật đã có ở compose, `scripts/migrate.sh`, `go`, `bazel`.
- **Cách làm & lý do**: mỗi target gọi đúng một công cụ có sẵn (`up` → `docker compose ... up -d --wait`, `migrate` → `scripts/migrate.sh up`, `test` → `go vet` + `go test -race`, `gazelle` → `bazel run //:gazelle`) — logic không bị lặp ở hai nơi, script vẫn chạy được không cần make (CI gọi thẳng script). `help` là `.DEFAULT_GOAL`: đọc comment `## mô tả` sau tên target bằng `grep` + `awk` → danh sách luôn khớp với target thật. `.PHONY` cho mọi target vì chúng không sinh ra file (có file tên `test` thì make vẫn chạy).
- **Bẫy / lưu ý**: recipe phải thụt bằng **TAB**. Mỗi dòng recipe chạy trong **một shell riêng** → `cd dir && lệnh` phải cùng dòng. `$$1` trong recipe = `$1` của awk (`$` đơn là biến make). macOS có GNU Make 3.81 — tránh cú pháp mới (`.ONESHELL`, `!=`...). Lệnh con lỗi → make dừng, trả mã 2 (TC04).
- **Code**: [Makefile](../../../../../../Makefile)

## Đường dẫn theo vị trí Makefile
- **Chủ đề**: `make`
- **Bối cảnh**: `make -C <repo>` hoặc gọi từ `com/tm/server` phải chạy đúng.
- **Cách làm & lý do**: `ROOT := $(dir $(abspath $(lastword $(MAKEFILE_LIST))))` — `MAKEFILE_LIST` là danh sách Makefile đã đọc, phần tử cuối là file hiện tại; `abspath` + `dir` ra thư mục tuyệt đối (có `/` cuối). Mọi đường dẫn khác ghép từ `ROOT`.
- **Code**: [Makefile — ROOT, COMPOSE, SERVER](../../../../../../Makefile)

## Đo P0-AT01 mà không phá DB đang dùng
- **Chủ đề**: `docker/compose`
- **Bối cảnh**: AT01 cần "máy sạch" (không volume, không container) nhưng máy dev đang có DB.
- **Cách làm & lý do**: clone repo ra thư mục tạm, đặt `COMPOSE_PROJECT_NAME=snaptix-at01` — biến môi trường **ưu tiên hơn** `name:` trong compose file → container, network, volume mới hoàn toàn; dừng DB chính bằng `make down` (giữ volume) để nhả cổng 5432; đo xong `down -v` project tạm rồi `make up` lại. Kết quả 3.8s khi image PG + module goose đã có trong cache.
- **Bẫy / lưu ý**: số đo chưa gồm tải image (~100 MB) và module Go trên máy thật sự sạch.
