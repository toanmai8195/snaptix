## Git chỉ theo dõi file, không theo dõi thư mục
- **Chủ đề**: `git`
- **Bối cảnh**: cần khung thư mục rỗng (`services/core`, `apps/bff`...) tồn tại sau khi clone.
- **Cách làm & lý do**: đặt `.gitkeep` trong từng thư mục lá. Thư mục cha tự có vì chứa thư mục con có file. Chọn `.gitkeep` thay vì README ở mỗi thư mục để không phải viết nội dung giả; các task sau sẽ thay bằng code thật.
- **Bẫy / lưu ý**: kiểm tra "sau clone còn thư mục không" bằng `git clone` chỉ thấy trạng thái đã commit. Trước commit, mô phỏng bằng index tạm: `GIT_INDEX_FILE=/tmp/idx git read-tree HEAD && git add -A && git checkout-index -a --prefix=/tmp/clone/` — kết quả tôn trọng `.gitignore` và bỏ thư mục rỗng giống clone thật, không đụng index thật.
- **Code**: [scripts/check-structure.sh#L12-L30 — REQUIRED_DIRS](../../../../../../scripts/check-structure.sh#L12-L30)

## Thứ tự pattern trong `.gitignore` và `git check-ignore`
- **Chủ đề**: `git`
- **Bối cảnh**: phải ignore `.env`, `.env.local`... nhưng giữ `.env.example`; ignore output Bazel (`bazel-bin`, `bazel-out`, `bazel-testlogs`, `bazel-<workspace>`).
- **Cách làm & lý do**: `.env` + `.env.*` rồi `!.env.example` — pattern phủ định phải đứng **sau** pattern nó phủ định. `bazel-*` bắt hết symlink output của Bazel bằng một dòng.
- **Bẫy / lưu ý**: `git check-ignore` mặc định trả "không ignore" cho file **đã được track** dù khớp pattern; dùng `--no-index` để kiểm tra thuần theo pattern. Đường dẫn kiểm tra không cần tồn tại.
- **Code**: [.gitignore#L69-L71 — .env](../../../../../../.gitignore#L69-L71), [.gitignore#L149 — bazel-*](../../../../../../.gitignore#L149), [scripts/check-gitignore.sh#L31-L34 — vòng kiểm tra](../../../../../../scripts/check-gitignore.sh#L31-L34)

## Shell script chạy được trên bash 3.2 của macOS
- **Chủ đề**: `bash`
- **Bối cảnh**: test dùng `mapfile` chạy tốt với bash 5 (Homebrew) nhưng `/bin/bash` của macOS là 3.2 — không có `mapfile`.
- **Cách làm & lý do**: thay bằng `while IFS= read -r d; do arr+=("$d"); done < <(...)`; chạy test bằng cả `/bin/bash` và `bash` để chắc chắn. Script nhận `ROOT` làm tham số để test được trên fixture tạm thay vì repo thật.
- **Bẫy / lưu ý**: trong zsh, trạng thái lệnh trong pipe là `$pipestatus` (chữ thường), không phải `$PIPESTATUS`.
- **Code**: [scripts/test/check-scripts.test.sh#L19 — đọc danh sách thư mục](../../../../../../scripts/test/check-scripts.test.sh#L19)
