## Cú pháp `.gitignore` và `git check-ignore`
- **Chủ đề**: `git`
- **Bối cảnh**: không commit output build của Bazel/Go và file rác của editor, nhưng phải giữ `go.mod`, `MODULE.bazel`, `BUILD.bazel`...
- **Cách làm & lý do**: pattern không có `/` khớp ở mọi cấp thư mục (`bazel-*` bắt `com/tm/server/bazel-bin`); `*` là wildcard (`bazel-*` bắt cả symlink `bazel-<tên workspace>`); `/` cuối chỉ khớp thư mục (`.idea/`); `!` phủ định và phải đứng sau dòng bị phủ định (`.env.*` rồi `!.env.example`).
- **Bẫy / lưu ý**: `git check-ignore` mặc định trả "không ignore" cho file **đã được track** dù khớp pattern — dùng `--no-index` để kiểm theo pattern; `-v` in ra dòng pattern gây ignore, rất tiện khi debug.
