## bzlmod: dependency Go lấy thẳng từ go.mod
- **Chủ đề**: `bazel`, `go/modules`
- **Bối cảnh**: cần một nguồn sự thật duy nhất cho dependency Go, không khai báo lại trong Bazel.
- **Cách làm & lý do**: `go_deps.from_file(go_mod = "//:go.mod")`. Thêm thư viện theo đúng thứ tự `go get` → `go mod tidy` → `bazel mod tidy` (tự thêm `use_repo(go_deps, "com_github_google_uuid")`) → `bazel run //:gazelle` (thêm `@com_github_google_uuid//:uuid` vào `deps`). Không có `bazel_dep` tay cho thư viện Go.
- **Bẫy / lưu ý**: quên `bazel mod tidy` thì Bazel báo repo chưa được `use_repo`. Tên repo theo quy ước đảo domain: `github.com/google/uuid` → `com_github_google_uuid`.
- **Code**: [MODULE.bazel#L30-L31 — go_deps](../../../../server/MODULE.bazel#L30-L31)

## Gazelle: prefix, naming convention và map_kind
- **Chủ đề**: `bazel`, `gazelle`
- **Bối cảnh**: target phải đặt tên theo package Go và mọi `package main` phải có sẵn image.
- **Cách làm & lý do**: `# gazelle:go_naming_convention import` → target mang tên package (`probe`, `probe_lib`) thay vì `go_default_library`. `# gazelle:map_kind go_binary com_tm_go_image //tools/rules:com_tm_container.bzl` → gazelle sinh lời gọi macro thay cho `go_binary`, vẫn cập nhật `embed`/`deps` bình thường khi chạy lại.
- **Bẫy / lưu ý**: gazelle chỉ sinh các thuộc tính của `go_binary`, nên macro phải chạy được với chừng đó tham số. Macro trong thor bắt buộc `package_name` → phải sửa BUILD tay; ở snaptix mặc định `native.package_name()` nên BUILD gazelle sinh ra chạy ngay.
- **Code**: [BUILD.bazel#L5-L8 — directive gazelle](../../../../server/BUILD.bazel#L5-L8), [com_tm_container.bzl#L50 — package_name mặc định](../../../../server/tools/rules/com_tm_container.bzl#L50)

## Macro com_tm_go_image: binary tĩnh + OCI image distroless
- **Chủ đề**: `bazel`, `oci`, `go/build`
- **Bối cảnh**: build image Go tái lập được, không cần Dockerfile hay Docker daemon lúc build.
- **Cách làm & lý do**: `go_binary(pure = "on", static = "on")` → binary không phụ thuộc libc, chạy được trên distroless. `copy_file` đưa binary từ `<name>_/<name>` ra `bin/<name>` để entrypoint cố định; `tar` đóng layer; `oci_image` trên `@distroless_base` (pin **digest**, không pin tag); `oci_load` → `com.tm.go.<name>:v1.0.0`; `oci_push` chỉ sinh khi có `repository`.
- **Bẫy / lưu ý**: trên macOS, action `CopyToDirectory`/`CopyFile` của rules_oci lỗi trong darwin-sandbox → `.bazelrc` cho chạy local. Image phải build theo kiến trúc máy chạy container: `--config=linux-arm64` (Apple Silicon) / `--config=linux-amd64` — cross-compile Go thuần nên không cần máy amd64. rules_oci + tar.bzl chưa chạy với Bazel 9 → pin 8.7.0.
- **Code**: [com_tm_container.bzl#L23-L101 — com_tm_go_image](../../../../server/tools/rules/com_tm_container.bzl#L23-L101), [.bazelrc#L14-L15 — strategy local](../../../../server/.bazelrc#L14-L15), [.bazelrc#L29 — config linux-arm64](../../../../server/.bazelrc#L29)

## git check-ignore và symlink của Bazel
- **Chủ đề**: `git`, `bazel`
- **Bối cảnh**: sau lần build đầu, `scripts/check-gitignore.sh` (P0-T01) fail với *"pathspec 'com/tm/server/bazel-out/x' is beyond a symbolic link"*.
- **Cách làm & lý do**: Bazel tạo `bazel-out`, `bazel-bin`... là **symlink** vào output base. Git không đánh giá đường dẫn đi xuyên symlink; kiểm tra chính symlink (`bazel-out`) — pattern `bazel-*` ignore nó.
- **Code**: [scripts/check-gitignore.sh#L12 — bazel-out](../../../../../../scripts/check-gitignore.sh#L12)

## Test hạ tầng bằng package tạm + trap
- **Chủ đề**: `bash`, `testing`
- **Bối cảnh**: kiểm chứng gazelle / go_deps / image cần code Go thật, nhưng task không được để lại code.
- **Cách làm & lý do**: script tạo `pkg/probe`, `services/probe` trong workspace, backup `go.mod`/`go.sum`/`MODULE.bazel`/`MODULE.bazel.lock`, và `trap cleanup EXIT` luôn xoá package tạm, khôi phục file, xoá image Docker — kể cả khi test fail giữa chừng.
- **Bẫy / lưu ý**: `sed -i ''` là cú pháp BSD (macOS); GNU sed dùng `sed -i`. Chạy script trên Linux/CI cần điều chỉnh (hoặc dùng python).
- **Code**: [scripts/test/bazel-setup.test.sh#L132 — sed chèn repository](../../../../../../scripts/test/bazel-setup.test.sh#L132)
