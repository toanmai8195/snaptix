## Chạy container bằng user non-root
- **Chủ đề**: `oci`, `security`
- **Bối cảnh**: image distroless `base` mặc định chạy bằng root.
- **Cách làm & lý do**: `oci_image(user = "65532:65532")` — distroless có sẵn user `nonroot` (uid 65532) trong `/etc/passwd`. Tiến trình bị chiếm quyền cũng không có root trong container. Binary Go tĩnh không cần ghi file hệ thống nên chạy non-root không vấn đề; cổng 8080 > 1024 nên không cần quyền bind cổng thấp.
- **Code**: [com_tm_container.bzl#L35, L89 — user](../../../../server/tools/rules/com_tm_container.bzl#L35)

## Gazelle giữ thuộc tính tự thêm
- **Chủ đề**: `bazel`, `gazelle`
- **Bối cảnh**: cần tag image có nghĩa (`com.tm.go.core-server`) thay vì tên thư mục (`server`), và khai báo `exposed_ports`.
- **Cách làm & lý do**: thêm tham số `image_name` cho macro, sửa tay `image_name`/`exposed_ports` vào BUILD do gazelle sinh. Gazelle chỉ quản các thuộc tính nó hiểu (`embed`, `deps`, `srcs`, `visibility`) — thuộc tính khác được giữ nguyên khi chạy lại; kiểm bằng `gazelle -mode=diff` không ra diff.
- **Code**: [cmd/server/BUILD.bazel](../../../../server/services/core/cmd/server/BUILD.bazel)

## Dừng êm trong container
- **Chủ đề**: `docker`, `go/signal`
- **Bối cảnh**: `docker stop` gửi SIGTERM rồi chờ `-t` giây mới SIGKILL.
- **Cách làm & lý do**: entrypoint là chính binary Go (dạng exec, không qua shell) nên binary là PID 1 và nhận SIGTERM trực tiếp → `signal.NotifyContext` kích hoạt dừng êm (P0-T09), exit code 0. Nếu entrypoint qua `sh -c` thì shell giữ PID 1, không chuyển tín hiệu → bị SIGKILL sau timeout (exit 137).
- **Code**: [worker/main.go#L53 — chờ ctx.Done](../../../../server/services/core/cmd/worker/main.go#L53)

## Kiểm tra tag image: đừng query build, hãy inspect
- **Chủ đề**: `bazel`, `oci`, `testing`
- **Bối cảnh**: test tìm chuỗi tag trong `bazel query --output=build` của target `_docker` thì không thấy.
- **Cách làm & lý do**: `oci_load` là macro, tag được ghi vào một file sinh ra (không nằm trong thuộc tính rule hiển thị). Kiểm tra đúng kết quả cuối cùng: load rồi `docker image inspect <tag>`; tương tự user, cổng, kiến trúc, kích thước đều lấy từ `docker image inspect`.
- **Code**: [core-image.test.sh](../../../../../../scripts/test/core-image.test.sh)
